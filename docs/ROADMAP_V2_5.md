# KT Opportunity V2.5 Roadmap

V2.5는 V2.4 FINAL Release Baseline 이후 기능 확장을 위한 Foundation 단계다.

## V2.5 Foundation

목표:

- Agent workflow 확장 기반 구축
- F-04/F-05 workflow 안정화
- n8n integration 준비
- Local LLM Gateway 연동 구조 정리
- API contract 확장 준비

## V2.5 Integration

목표:

- KT Opportunity backend integration
- n8n workflow 연결
- FastAPI Gateway 연동
- 운영 환경 검증

## V3.0 Production Architecture

목표:

- Production architecture 전환
- 운영 데이터 기반 검증
- Agent orchestration 확장
