## Project Pivot

V0.4 → V1 구간에서 프로젝트의 제품 과제와 도메인이 전환됐다.

- 이전: 건축물 데이터 기반 KT 인터넷 영업 후보지 발굴 및 방문 준비 Agent
- 이후: 신규 음식점 영업 기회 발굴 및 맞춤 상품 설계 AI Agent
- 제품명: KT Sales Agent → KT Opportunity

V1은 KT Opportunity로의 공식 Project Pivot이다.
